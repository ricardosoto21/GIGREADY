# GigReady - Roadmap

## Version 1.2.0-beta.1

- [x] Escaneo completo unico.
- [x] Seleccion de genero antes del escaneo.
- [x] Perfiles de energia por genero.
- [x] Perfiles nuevos: Psytrance y Minimal / Minimal Techno.
- [x] Exportacion enfocada en M3U y Rekordbox XML.
- [x] XML con memory cues aprobados y estrellas.
- [x] Vista de pasos posteriores para Rekordbox despues de exportar XML.
- [x] Editor de cues con navegacion Anterior / Siguiente.
- [x] Preview de audio desde cues.
- [x] Zoom y arrastre de marcadores en mapa de energia.
- [x] Conversor independiente a MP3, WAV y AIFF.
- [x] FFmpeg y FFprobe Windows x64 bajo LGPL verificados.
- [x] Documentacion beta: instalacion, protocolo y formulario.
- [x] Reduccion de ruido por metadata incompleta.
- [x] Avisos internos cuando la grilla de beat puede requerir revision.

## Antes De Beta Publica

- [ ] QA manual completo en Windows 10 y Windows 11.
- [ ] QA manual con Rekordbox real para XML, estrellas y memory cues.
- [ ] Capturas reales para `docs/rekordbox-import.md`.
- [ ] Paquete beta compartible con instalador, checksums y docs.
- [ ] Decision sobre firma digital de Windows.
- [ ] Revision legal final de distribucion FFmpeg/FFprobe.
- [ ] Politica de soporte para beta testers.
