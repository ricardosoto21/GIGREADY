# Nota para beta testers - Instalacion en Windows

GigReady `1.2.0-beta.1` es una beta privada. El instalador todavia no tiene firma digital de Windows.

Por eso Windows SmartScreen puede mostrar una advertencia como:

```text
Windows protegió su PC
Editor desconocido
```

Esto ocurre porque la beta aun no esta firmada con un certificado de publicador. No significa por si solo que el archivo este danado, pero si significa que debes instalarlo solo si recibiste el enlace directamente del equipo de GigReady.

## Recomendaciones

1. Descarga el instalador solo desde el enlace privado recibido.
2. No redistribuyas el instalador.
3. Prueba primero con copias de tu musica.
4. Mantén respaldo de tus carpetas importantes.
5. Reporta cualquier alerta o error con captura de pantalla.

## Archivo correcto

```text
GigReady Setup 1.2.0-beta.1.exe
```

Si recibes otro nombre de archivo, confirma antes de instalar.
